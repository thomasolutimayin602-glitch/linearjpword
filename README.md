# 語詞 · 日语背单词（toword-jp）

移动优先的日语背单词 Web App / PWA。产品范围、页面路由与验收标准见仓库上一级的 `拓词日语开发蓝图-v1.md` 和 `拓词英语版分析与日语版产品需求文档-v1.md`。

## 技术栈

- React 19 + TypeScript + Vite 8
- React Router 7
- Zustand
- Dexie / IndexedDB
- Tailwind CSS 4
- Vitest

## 常用命令

```sh
npm run dev      # 本地开发服务器
npm run build    # TypeScript 检查 + 生产构建
npm run lint     # oxlint
npm test         # Vitest 单元测试
npm run preview  # 预览生产构建
```

## 当前能力

- 欢迎页、协议确认、游客试学（10 题）、本地学习档案与 4 步 onboarding。
- 日语内容模型：日语词形、假名、罗马音、中文释义与中文例句；英文原义仅作为内部来源字段保留，不在主界面展示。
- 内置内容 Provider 与 5 本 N5 开发期词书（核心、日常、自然、人物、出行），可离线使用，不伪装为正式 N4/N3 词书。
- 当前词书持久化；按词书过滤每日新词与复习，切换词书后重新生成当天计划，历史学习进度不删除。
- 每日计划持久化，首页、档案页和训练会话共享同一份计划与完成进度。
- 训练可随时暂停并从原题、原题型和原进度恢复；直接刷新 `/study` 也会继续未完成会话。
- 首页在跨日或重新聚焦时刷新今日计划；结果页支持系统分享，不支持时复制结果文本。
- 五步训练链：听读 → 选义 → 选词 → 假名拼写 → 例句。
- 假名键盘（清音 / 浊音 / 拗音 / 片假名）、罗马音输入、平假名/片假名宽松判定。
- 1 / 7 / 15 / 30 天复习阶梯、置顶、错词本、错词专项训练、撤销。
- 查词、单词详情、收藏、词书库/词书详情、学习统计、设置持久化。
- PWA manifest 与生产环境 Service Worker 离线壳。

## 目录

```text
src/
  components/   通用 UI 与图标
  content/      内容 Provider、词书定义与内容测试
  data/         开发期中文释义/例句种子词条
  db/           Dexie schema 与迁移
  engine/       复习调度、罗马音/假名判定
  lib/          本地日期等工具
  pages/        路由页面
  stores/       Zustand 学习状态
  types/        领域类型与默认设置
```
